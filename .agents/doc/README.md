# Documentação do Usuário — Atlas Financeiro

Base de conhecimento para a futura tela de documentação do sistema.
Esta pasta contém guias práticos, passo a passo, para o uso do Atlas Financeiro.

## Estrutura

- `configuracao/contas.md` — cadastro e gestão de contas financeiras.
- `configuracao/categorias.md` — categorias de despesa/receita.
- `configuracao/orcamentos.md` — tetos mensais por categoria.
- `configuracao/regras.md` — regras de categorização automática.
- `configuracao/conta-perfil.md` — perfil, tema, idioma e sessão.
- `lancamentos.md` — lançamentos (entradas, saídas, split, filtros, ações em massa).
- `transferencias.md` — transferências entre contas.

## Ordem recomendada de configuração inicial

1. Criar **contas** (onde o dinheiro está).
2. Criar **categorias** (como classificar gastos/receitas).
3. Criar **orçamentos** (tetos por categoria e mês).
4. (Opcional) Criar **regras** de categorização automática.
5. Ajustar **perfil** (tema/idioma).
6. Começar a lançar em **Lançamentos**.

> Sem contas e categorias, o módulo de Lançamentos fica limitado: não há onde lançar nem como classificar.
