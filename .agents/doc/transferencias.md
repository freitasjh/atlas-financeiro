# Transferências entre Contas

**Onde encontrar:** Lançamentos → botão **Nova transferência** (disponível quando há ao menos 2 contas cadastradas). Também pode ser acionado pela busca rápida.

## O que é uma transferência

Uma transferência move dinheiro de uma conta para outra (ex.: da conta corrente para a poupança). É uma **movimentação interna**: não é receita nem despesa e não afeta o resultado do período nem os orçamentos.

## Para que serve

- Mover dinheiro entre contas próprias.
- Reservar valores (ex.: transferir para poupança).
- Manter saldos corretos em cada conta.

## Como fazer uma transferência

1. Na tela de Lançamentos, clique em **Nova transferência**.
2. Preencha:
   - **Origem**: conta de onde sai o dinheiro.
   - **Destino**: conta para onde vai o dinheiro.
   - **Valor** (maior que zero).
   - **Data** (data da transferência).
   - **Descrição** (opcional): ex.: "Reserva mensal".
3. O sistema mostra o **saldo disponível na origem** para conferência.
4. Clique em **Transferir**.

### Regras

- Origem e destino devem ser **contas diferentes**.
- O saldo da conta de origem deve ser **suficiente** para o valor transferido.
- Transferências **não aceitam categoria** (são movimentações internas).
- O valor deve ser maior que zero.

## Como aparece na lista

A transferência aparece como uma linha com tipo "Transferência", sem categoria. Ela não entra no resumo de Entradas/Saídas nem nos orçamentos.

## Efeito nos saldos

- Conta de origem: saldo diminui.
- Conta de destino: saldo aumenta.
- Ambos os saldos são recalculados automaticamente.

## Boas práticas

- Use descrições claras para identificar a finalidade (ex.: "Reserva de emergência").
- Confira o saldo disponível antes de transferir.
- Evite transferências com data futura se quiser que afetem o saldo imediatamente.

## Problemas comuns

- **"Origem e destino devem ser contas diferentes"** → selecione contas distintas.
- **"Saldo insuficiente na conta de origem"** → reduza o valor ou escolha outra conta de origem.
- **Botão não aparece** → é necessário ter ao menos 2 contas cadastradas.
