# Conta de Usuário (Perfil, Tema, Idioma e Sessão)

**Onde encontrar:** Configurações → card **Conta**.

## O que é

Tela de perfil do usuário autenticado: exibe o e-mail, permite trocar tema e idioma, e encerrar a sessão.

## Funcionalidades

- **E-mail** exibido (somente leitura).
- **Tema/Idioma**: alternância entre claro/escuro e português/inglês.
- **Sair**: encerra a sessão e retorna à tela de login.

## Como usar

1. Acesse Configurações → **Conta**.
2. Alterne tema e idioma conforme sua preferência.
3. Para sair, clique em **Sair**.

## Observações

- A autenticação é feita por e-mail e senha, link mágico ou login social.
- A sessão é mantida de forma segura; não há senha ou token visível no navegador.
- Se a sessão expirar, as telas protegidas redirecionam para o login.
