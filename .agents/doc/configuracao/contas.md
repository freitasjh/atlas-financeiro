# Contas Financeiras

**Onde encontrar:** menu lateral → **Contas**.

## O que é uma conta

Uma conta representa onde seu dinheiro está guardado: conta corrente, poupança, dinheiro em espécie ou investimento. Cada conta possui um saldo que o sistema calcula automaticamente.

## Para que serve

- Acompanhar o saldo de cada conta separadamente.
- Servir de base para lançamentos de despesa, receita e transferência.
- Somar os saldos em "Total em contas".

## Como acessar

1. No menu lateral, clique em **Contas**.
2. Ou use a busca rápida (Ctrl/Cmd + K) e digite "Contas".

## Criar uma conta

1. Clique em **Nova conta**.
2. Preencha:
   - **Nome** (obrigatório): ex.: "Conta corrente Itaú".
   - **Tipo** (obrigatório): Corrente, Poupança, Dinheiro ou Investimento.
   - **Saldo inicial** (obrigatório): valor atual da conta. Ex.: 1.500,00.
3. Clique em **Salvar**.

### Dicas de preenchimento

- Use vírgula para centavos: `1500,00`.
- O saldo inicial não pode ser negativo.
- O nome deve ter entre 1 e 120 caracteres.

## Editar uma conta

1. Clique no ícone de lápis ao lado da conta.
2. Altere o **Nome** e/ou o **Tipo**.
3. O **Saldo atual** aparece apenas para consulta — não é editável.
4. Clique em **Salvar**.

> O saldo é recalculado automaticamente após a edição, com base no saldo inicial e nos lançamentos.

## Excluir uma conta

1. Clique no ícone de lixeira.
2. Confirme a exclusão.
3. **Não é possível excluir** uma conta que possua lançamentos vinculados. Exclua ou mova os lançamentos primeiro.

## Tipos de conta

| Tipo | Uso típico |
|------|-----------|
| Corrente | Conta bancária do dia a dia |
| Poupança | Reserva de emergência |
| Dinheiro | Carteira/espécie |
| Investimento | Aplicações |

## Como o saldo é calculado

- Saldo atual = saldo inicial + lançamentos concluídos até hoje.
- Lançamentos com data futura (agendados) só entram no saldo quando a data chegar.
- Despesa diminui o saldo; receita aumenta.
- Transferência entre contas: sai da origem e entra no destino.
- Pagamento de fatura de cartão não é despesa — é movimentação interna entre conta e cartão.

## Boas práticas

- Cadastre uma conta por instituição/uso (ex.: "Nubank corrente", "Itaú poupança").
- Informe o saldo inicial igual ao saldo real do extrato na data em que começa a usar o sistema.
- Cartões de crédito são cadastrados em **Cartões**, não em Contas.

## Problemas comuns

- **Não consigo excluir a conta** → há lançamentos vinculados; exclua-os ou mova para outra conta.
- **Saldo não bate com o banco** → verifique lançamentos futuros (agendados) e transferências; o saldo considera apenas lançamentos com data de hoje ou anterior.
